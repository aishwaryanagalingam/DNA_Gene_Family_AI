# 🧬 DNA Gene Family AI

An AI-powered machine learning project that predicts the gene family of a DNA sequence.

## 🚀 Features

- DNA sequence input
- Gene family prediction
- Prediction confidence
- Class probability display
- Interactive Streamlit web interface
- Machine learning model using TF-IDF and Logistic Regression

## 🧠 Machine Learning

The model uses:

- Character-level TF-IDF
- 3–5 nucleotide n-grams
- Logistic Regression
- 2,000 synthetic DNA sequences
- 4 gene-family classes

### Gene Families

- Family_A
- Family_B
- Family_C
- Family_D

## 📊 Model Accuracy

**100% accuracy on the test dataset**

> Note: The dataset used in this project is synthetic and created for educational purposes. The reported accuracy applies only to this synthetic dataset and does not represent real-world biological gene-family classification.
